# Exam Score Prediction

## Overview
This project uses machine learning to predict students' exam scores based on relevant input features. A Random Forest Regressor is used to learn patterns from the data and generate score predictions.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Model
**Random Forest Regressor**

Random Forest is an ensemble learning algorithm that combines multiple decision trees to predict numerical values.

## Model Performance
- **Mean Absolute Error (MAE):** 0.6

The MAE measures the average absolute difference between the actual exam scores and the model's predictions. An MAE of 0.6 means that the average absolute prediction error is 0.6 score units on the evaluation data.

## Example Prediction
- **Predicted Exam Score:** 85

- Data preprocessing
